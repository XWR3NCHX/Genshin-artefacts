# Bibliothèque de farm Genshin Impact

Catalogue fan-made d'artéfacts et de livres d'amélioration d'aptitude.

## Fonctionnalités
- Basculer entre le catalogue d'artéfacts et celui des matériaux d'aptitude.
- Filtrer par rareté et rechercher par nom.
- Consulter les fiches détaillées et les jours de disponibilité des livres d'aptitude.
- Ajouter artéfacts et matériaux dans une seule planification hebdomadaire.
- Choisir plusieurs jours de farm par élément ; les choix sont enregistrés dans le navigateur.
- Informations de domaine et cartes de localisation dans les fiches d'artéfacts lorsqu'une image est disponible.

## Installation
Publie le contenu de ce dossier sur GitHub Pages ou ouvre `index.html` via un serveur local.

Les catalogues sont récupérés auprès d'API communautaires. Leur disponibilité et leurs champs peuvent changer ; une connexion Internet est nécessaire.

Projet non officiel, non affilié à HoYoverse.

## Noms des images des matériaux
Chaque image doit être au format PNG et porter exactement le nom indiqué dans la colonne `image` de `materiaux.json` (ex. `philosophies-of-freedom.png`). Les noms doivent être en minuscules, sans accents ni espaces.
